# Smiley Widget

## Overview

Smiley Widget is a jumping happy face that lives near the bottom of your screen and it also functions as a timer, and looks fun. This is my first attempt at a project that isn't in python or GDscript and was compiled with Electron. Check their repository out too, [here](https://github.com/electron/electron).
